# 替换表

欧化写法和黑话到简明写法。这张表是本项目自己整理的，来源在末尾。如果一个词不带事实，删掉它，不要替换。

## 弱动词

| 原写法 | 简明写法 |
|---|---|
| 进行部署 / 进行分析 / 进行检查 | 部署 / 分析 / 检查 |
| 作出评估 / 做出决定 / 作出响应 | 评估 / 决定 / 响应 |
| 予以处理 / 予以调整 | 处理 / 调整 |
| 加以说明 / 加以解决 | 说明 / 解决 |
| 开展相关工作 | 写出实际做的事 |
| 实施改造 / 实施方案 | 改造 / 执行方案 |
| 对配置文件进行修改 | 修改配置文件 |
| 实现了效率的提升 | 快了多少，写数字 |
| 造成九十八人死亡 | 死了九十八人 |

## 情态词

| 原写法 | 简明写法 |
|---|---|
| 应该 / 应当 / 务必（要求） | 必须 |
| 应该（猜测） | 可能 |
| 最好 / 尽量 / 宜 | 建议，或者删掉直接说事实 |
| 需要（要求） | 必须 |
| 可以（说能力时） | 能 |
| 能（说允许时） | 可以 |
| 可能（说允许或能力时） | 可以 / 能 |

## 名词化和虚字

| 原写法 | 简明写法 |
|---|---|
| 可读性高 | 好读 |
| 稳定性差 | 不稳定 |
| 具有很高的知名度 | 很有名 |
| 实现自动化 | 自动执行 |
| 名著之一 | 名著 |
| 用户们 / 人们 | 用户 / 人 |
| 有关文档的种种 / 关于配置的问题 | 文档的种种 / 配置的问题 |
| 成功地推翻了 | 推翻了 |
| 基于这个原因 | 因此 |
| 有很多问题存在 | 问题很多 |
| 服务器端的连接池的超时时间的默认值 | 服务器连接池的超时默认值 |
| 起步更早及迈步更快 | 起步更早而迈步更快 |

## 被字句

| 原写法 | 简明写法 |
|---|---|
| 该请求被服务器成功处理了 | 服务器处理了该请求 |
| 我不会被你这句话吓倒 | 你这句话吓不倒我 |
| 文件已经被删除了 | 文件已删除 |
| 该功能应该可以在安装后被正常使用 | 安装后，该功能正常运行 |

## 空洞词和黑话

| 原写法 | 简明写法 |
|---|---|
| 值得注意的是 / 需要指出的是 / 不难发现 | 删掉，直接说事实 |
| 综上所述 / 总的来说 / 总而言之 | 删掉 |
| 至关重要 / 举足轻重 / 深远影响 | 说为什么重要，或者删掉 |
| 不是 X 而是 Y / 不仅 X 更 Y | 直接说 Y |
| 随着…的不断发展 / 在当今…时代 | 删掉 |
| 赋能 | 帮、让…能 |
| 抓手 | 方法、工具 |
| 闭环 | 说完成了什么；闭环控制、闭环反馈保留 |
| 一站式 / 全链路 | 列出实际包含的功能或阶段 |
| 底层逻辑 | 原理、原因 |
| 颗粒度 | 粒度、细节 |
| 降本增效 | 给数字 |
| 助力 / 打造 | 帮 / 做、建 |
| 无缝 / 颠覆性 | 说兼容条件 / 说改变了什么 |
| 沉淀 | 说保存或积累了什么 |
| 拉通 / 打通 / 对齐 | 说连接或统一了什么 |
| 兜底 / 透传 | 说失败后的保障 / 说哪些数据原样传给谁 |

## 开场白和结束语

| 原写法 | 简明写法 |
|---|---|
| 好的 / 当然 / 没问题 / 您好 | 删掉，直接给答案 |
| 感谢您的提问 / 这是一个很好的问题 | 删掉 |
| 关于您提到的问题 | 删掉 |
| 希望对你有帮助 / 如有问题欢迎继续提问 / 请随时告诉我 | 删掉 |

## 来源

弱动词、名词化、虚字、被字句来自余光中《怎样改进英式中文？论中文的常态与变态》（《明报月刊》1987 年 10 月号）。情态词来自 GB/T 1.1-2020 附录 C 的五类分法，用词的偏离见 `docs/design.md`。空洞词和黑话来自 lieflat 语料实测、中文维基百科《AI 生成文的特征》、Fenng/Tech-Doc-Style-Chinese 的黑话表、MrGeDiao/shuorenhua 的 Tier 1 词表和 EsserZ/controlled-technical-chinese 的 jargon 表。
